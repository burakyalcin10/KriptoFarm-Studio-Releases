# KriptoFarm Studio

Windows 64 bit için uygulama dağıtımı. Kaynak kodu bu depoda bulunmaz.

[Küçük başlatıcıyı indir](https://github.com/burakyalcin10/KriptoFarm-Studio-Releases/releases/latest/download/KriptoFarmStudio-Launcher.zip)

1. ZIP dosyasının tamamını yazılabilir bir klasöre ayıklayın.
2. İçindeki `BASLAT.bat` dosyasını açın; `scripts` klasörü yanında kalmalıdır.
3. İlk açılışta güncel uygulama indirilir ve başlatılır.

Başlatıcı birkaç KB'dır. İlk uygulama indirmesi yaklaşık 132 MB, kurulu hali
yaklaşık 326 MiB'dir. Yeni sürüm yayımlandığında sonraki açılışta otomatik
indirilir. Bağlantı kesilirse önceden kurulmuş sürüm açılır. Python kurulumu
ve GitHub hesabı gerekmez. İlk kurulumda internet gereklidir.

Oyun istemcisi ve Tesseract dahil değildir. OCR/farm için Tesseract-OCR ile
İngilizce (`eng`) verisini ayrıca kurun. Ekran kalibrasyonunu ve farm planını
kendi bilgisayarınızda oluşturun. Kayıtlar başlatıcının yanındaki `data`
klasöründe tutulur. Oyun sürümü değiştiğinde Studio uyumluluk güncellemesi
gerekebilir.

Tüm paketler [Releases](https://github.com/burakyalcin10/KriptoFarm-Studio-Releases/releases)
sayfasındadır. `windows-x64.zip` başlatıcının kurduğu tam uygulama paketidir.
